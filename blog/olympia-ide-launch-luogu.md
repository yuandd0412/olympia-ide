# 你的新一代 IDE:Olympia IDE

在这个充满寓意着的日子里,我们正式宣布:**Olympia IDE v0.1.0 现已发布!**一款专为 OIer 打造的桌面 IDE,把"刷题 → 写题 → 调题 → 复盘"这条流水线上所有的脏活累活自动化。完全开源(MIT)。

## 产品简介

Olympia IDE 的前身是一个叫 Oler IDE 的 Qt 项目(是的,就是那个只有 OIer 才懂的称呼)。后来我们意识到:与其在旧框架里缝缝补补,不如推倒重来。整个项目用 Tauri 2 + React 19 + Rust 重写,评测、对拍、终端进程管理全部在 Rust 侧完成。

名字的寓意也在这里:奥林匹亚,是奥运会举办的地方,而 NOI / NOIP / CSP 的全称里写的就是"信息学**奥林匹克**"。Logo 是一枚「判定环」——O 是 Olympia 的首字母,也是奖牌的环、AC 的判定圈;那道缺口是进行时态,因为永远还有下一题。

## 功能一览

- [x] 内置评测机:多样例毫秒级比对,自动判定 AC / WA / TLE / MLE / RE,逐字符 diff 定位第一个不一致的输出
- [x] 自动化对拍器:内置数据生成器,正解、暴力、生成器三份代码丢进去,批量对拍,自动捕获反例
- [x] PDF 试卷导入:自动识别"第 N 题 / T1"式标题并切分成题,导入即测;支持**一键创建比赛**或存为题集
- [x] 比赛模式:NOIP / CSP 式倒计时,期间 AI 教练自动锁定,归零自动解锁
- [x] AI 竞赛教练:接入你自己的 API Key(DeepSeek / OpenAI 等兼容接口),防剧透思路提示、复杂度分析、Bug 排查
- [x] 洛谷题面一键同步:LaTeX 公式完整渲染,缓存本地,离线可看
- [x] 训练计划 + 错题本:按判定结果自动归档,赛后复盘有迹可循
- [ ] Codeforces / AtCoder 题目导入与一键提交
- [ ] 智能代码补全
- [ ] 便携版、更多主题

## 注意事项

1. 安装需要管理员权限(全机安装),会自动创建开始菜单和桌面快捷方式;
2. 精简版首次启动需要联网下载工具链(约 69 MB,清华 TUNA 镜像);
3. 部分"智商很高"的杀毒软件可能对未签名安装包误报,添加信任即可;
4. 洛谷题面走公开接口拉取并缓存到本地 `~/.oleride/problems.json`,不登录、不上传、不采集任何账号信息。

## FAQ

::::info 什么是"题集"和"比赛记录"?
导入 PDF 时可以二选一:**创建比赛**(设定时长,立刻进入倒计时锁 AI 的比赛模式)或**导入为题集**(日常练习用,随时改名)。两者都会存进练习记录,在题面阅读器顶部可以随时切换。
::::

::::info PDF 自动识别识别不出我的卷子怎么办?
自动识别认的是"第 N 题 / T1 / Problem 2"这类标题。CSP/NOIP 卷子里"一、二、三"是章节不是题目,所以会被故意跳过。识别不到没关系:阅读器里可以手动按页码区间标记题目,标记完一样出现在题目列表里。
::::

::::info 为什么第一次保存 / 编译的时候弹出了文件选择框?
正常的 IDE 行为:编译前代码会先写入磁盘,首次保存需要你指定位置,选好以后同一个标签页就会静默保存到原位置,不会再问。
::::

::::info 你们的 AI 教练要收费吗?
不收费,但需要你自己在设置里填一个大模型 API Key(DeepSeek / OpenAI 等兼容接口都行)。我们不做中转、不碰你的 Key,它只和你填的服务器通信。
::::
