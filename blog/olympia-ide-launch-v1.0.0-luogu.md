## 正文

今天把 Olympia IDE 的第一个正式版本发出来了，v1.0.0。

一句话：它是一个基于 VS Code 1.140.0 的编辑器，把刷题这条链路上散落的环节接在一起——拉题面、写代码、用题面样例本地判一次 AC/WA、跟暴力对拍找反例、比赛时给自己开一段倒计时、做完记一道。

### 为什么不直接用 VS Code

VS Code 本身很好，但它不知道评测机是什么。

洛谷的评测机是 GCC 15.1.0、`-std=c++23`，开关是 `-fPIC -DONLINE_JUDGE -Wall -fno-asm -lm -march=native`；洛谷默认的 NOI Linux 2.0 提交语言是 GCC 9.3.0、`-std=c++14`。你按自己的习惯配好编译器，本地跑得好好的，提交上去可能 WA、可能 TLE —— 原因往往只是几个宏或开关对不上。

两个容易踩的点：

- `-DONLINE_JUDGE` 是个**没有值**的宏，写成 `ONLINE_JUDGE=luogu` 的话 `#ifdef` 是测不出来的（那是评测机给的环境变量，另一回事）。
- 洛谷改过 GCC，用优化 pragma 或 attribute 会让编译直接失败。

所以 Olympia 把评测机参数写进一张表，编译路径和界面上每一处描述都从这张表读，不会各说各话。档位有三档：洛谷、NOI Linux 2.0（洛谷默认提交语言），以及自己填参数的自定义档。

### 具体做了什么

**编译环境对齐评测机**

- 内置 MinGW-w64 GCC 15.2.0，装完就能按 F9 编译，不用自己先装一套编译器
- 有一键「环境自检」，把当前编译器版本和标准直接打出来
- 评测机档位一键切换，编译命令可以整条打印出来

**本地判题**

- **跑样例**：拿题面的样例跑一遍，给出 AC / WA / RE / TLE / MLE（内存超限那档要题面写了内存限制才判，否则只报峰值）
- **对拍**：正解对暴力，随机生成数据，把反例和触发它的数据一起留给你
- **提交前体检**：提交之前先把容易翻车的地方过一遍

**比赛模式**

给自己开一场带倒计时的比赛，时长自己选，到点收工。适合赛前限时模拟。

**题面与训练**

- 从洛谷 / Codeforces / AtCoder 拉题面（也可以直接从剪贴板拉题号）
- 题面库，本地题面也能进
- 给某道题补一组自定义样例（对拍抓到的反例也能补进去）
- 集训清单：把要刷的题排成一张单子，带时长
- 插入赛制模板，或者改自己的模板
- 解题记录与连续打卡

**另外**

- 十分钟上手的引导演练，不认识功能的时候照着走一遍
- AI 教练：自带 baseUrl 和 API Key 用，不绑账号、不订阅、不过我们的服务器，出厂包不带任何模型
- 扩展市场走 open-vsx
- 常用动作都绑了快捷键，左侧面板上直接写着，不用去命令面板里翻

**机房友好**

编译、运行、体检、跑样例、对拍、比赛模式、模板、已缓存的题面——这些全都离线可用。需要联网的只有两件：拉在线题面和用 AI 教练。

### 现在的边界

说清楚点，免得有人白折腾：

- 目前主要面向 Windows
- 题面拉取依赖各站点自己的接口，站点改了接口就得等我们跟着改
- Codeforces 的题面页有人机校验，正文抓不到时 Olympia 会留下题目信息和原题链接，剩下部分请在浏览器里看
- AI 教练要自己准备 API Key，出厂包不带任何模型
- 这是第一个正式版本，遇到问题欢迎回帖

有问题、或者想要某个功能，直接回帖说。
