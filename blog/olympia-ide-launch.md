# 我给 OI 选手写了一个 IDE:Olympia IDE

一个从"刷题 → 写题 → 调题 → 复盘"都想帮你省时间的一次尝试,今日正式发布,完全开源(MIT)。

## 你是否也受够了这些

- 新机器配环境:找 MinGW、认 ABI、配 PATH,折腾一晚上才开始写第一道题;
- 评测靠肉眼 diff,样例过了 WA 了不知道差在哪个字符;
- 对拍全靠手搓数据生成器和批处理脚本;
- 模拟赛想找比赛的感觉,结果 AI 工具就摆在旁边,意志力天天经受考验;
- 赛后想复盘,错题和当时的代码早已散落在各个文件夹里。

这些都是我(和身边每个 OIer)真实经历过的日常。所以我写了 **Olympia IDE**——一款专为 OI / ACM 竞赛选手打造的桌面编程 IDE,把这条流水线一次性做完。

## 它能做什么

**内置极速评测**:保存即编译,多样例毫秒级比对,自动判定 AC / WA / TLE / MLE / RE,逐字符 diff 告诉你第一个不一致的输出。评测全程静默无黑窗;喜欢 Dev-C++ 感觉的可以切到终端优先模式,一键弹出 CMD 交互运行。

**自动化对拍器**:内置随机数据生成器,把你写的正解、暴力、生成器三份代码丢进去,批量对拍,自动捕获让暴力挂掉的反例。

**题库 · 训练 · 错题本**:本地题库沉淀题目(支持洛谷题面一键同步,离线可用),训练计划追踪连续打卡,错题本按判定结果自动归档,赛后复盘有迹可循。

**PDF 试卷一键导入**:拿到 CSP/NOIP 卷子的 PDF?导入后自动识别题目切分,可以选择**创建一场比赛**(倒计时启动,AI 教练自动锁定,归零解锁)或存为**题集**进入练习记录。整张卷子从此变成你的私人赛题库。

**真实比赛模式**:NOIP / CSP 式倒计时,期间 AI 全程锁定——工具应该模拟赛场,而不是替你上场。

**AI 竞赛教练**:接入你自己的大模型 API(DeepSeek / OpenAI 等兼容接口),提供防剧透的思路提示、时空复杂度分析、边界 Bug 排查。平时是陪练,赛时懂得闭嘴。

**其他细节**:真保存系统(编译前自动落盘,再也不怕代码只活在内存里)、One Dark Pro / GitHub Light 双主题、全中文界面、`Ctrl+R` 一键评测。

## 为什么叫 Olympia

奥林匹亚,是古代奥林匹克运动会的举办地——"奥林匹克"是一切竞赛的源头。而对 OIer 来说这个词更直接:NOI、NOIP、CSP 的全称里,写的都是"信息学**奥林匹克**"。

Logo 是一枚「判定环」:O 是 Olympia 的首字母,也是奖牌的环、AC 的判定圈;缺口是进行时态——永远还有下一题;那一点绿,是每个 OIer 每天在追的两个字母。

(仓库代号 `oler-ide-v2` 是历史遗留:v1 时代它叫 Oler IDE,来自 OIer 这个自嘲式的称呼。v2 重写时,决定让它配得上一个更正式的名字。)

## 下载

官网(介绍 + 双版本下载):**https://olympia.dpdns.org**

两个版本任选,均为全中文安装器:

- **精简版**(约 6 MB):安装后首次启动,自动从国内镜像(清华 TUNA)下载 MinGW 13.1.0 编译工具链,国内下载速度很好;
- **完整版**(约 49 MB):内置 MinGW 13.1.0 工具链,离线开箱即用,适合机房与弱网环境。

- GitHub Releases:<https://github.com/yuandd0412/olympia-ide/releases>
- 完整版国内直连(Gitee):<https://gitee.com/yuanddMSK/olympia-ide/releases/download/v0.1.0/Olympia%20IDE_0.1.0_x64-full-setup.exe>
