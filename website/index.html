为竞赛写的那部分

这些是 Olympia 自己加的，不是插件市场里拼出来的。

自带编译器

MinGW-w64（GCC 15.2.0，posix 线程模型）整个打进安装器。机房机器上什么都没有也能直接编译， 不需要装任何东西、不需要配环境变量。

bits/stdc++.h 与 pthread.h 都在包里。

评测机参数预设

洛谷（C++23）、NOI（C++14）、自定义三档。状态栏左下角常驻显示当前档位， 点一下就能换；把评测机的开关套到本地编译，避免「本地过、评测机挂」。

-x c++ -std=c++23 -fPIC -DONLINE_JUDGE -Wall -fno-asm -lm -march=native

提交前体检

保存时扫描会在评测机上导致编译失败的写法，只报真会挂的，不管代码风格：

  • #pragma GCC optimize 一类优化属性
  • asm、and、or、not 等 MSVC 能用、GNU C++ 是关键字的名字
  • gets、random_shuffle 等 C++17 起删掉的设施

拉题面

洛谷、Codeforces、AtCoder 题号或链接直接拉进编辑器，也可以从剪贴板识别。 题面、样例、代码在同一个窗口里，不用来回切浏览器。攒到几十道之后题库按 ★ 收藏排： 点过星的排最前，敲 ★ 就只剩它们，做过的自带 ✓。

写完按 Ctrl+Alt+U 回到这道题的原网页交题，链接不用从题面里复制。

跑样例

拉完题面后按 Ctrl+Alt+J，用题面里的样例数据测当前代码， 按 token 比对、读题面里的时限与内存限制，给出 AC / WA / RE / TLE / MLE。不联网、不需要账号，纯本地判定。

判成 WA 会说清是第几行第几个数不同，还是少输出了一行；再按 Ctrl+Alt+K 把期望与你的输出并排摊开。

对拍

选正解、暴力、生成器三个文件，Olympia 编译好之后按轮数喂随机数据，两边输出按 token 比对。 不一致就停下，把那组数据和两份输出写进 stress-fail/，直接点开看； 想留住它，点一下 补进题面样例，以后每次跑样例都会带着这组数据。

不用装 Python，不用手写 fc 脚本，全程不弹命令行窗口。

比赛模式

选一段时长（60 / 90 / 120 / 180 / 240 / 300 / 360 分钟，或自己填），状态栏出现倒计时， 侧栏「当前环境」同步显示剩余时间。重载窗口也接着走，点一下倒计时可以提前收摊。

倒计时期间 AI 教练自动锁住：自己练就不该是开卷。

模板与键位

ACM / IOI 赛制模板一键插入；用不惯就写自己那一份 —— 面板点「编辑我的模板」打开工程里的 .olympia/template.cpp，保存之后每次插的都是它，拉题面建的文件也从它打底。 另有 20 条竞赛常用写法的补全：快速 IO、freopen、 并查集、快速幂、Dijkstra，中英文都搜得到。 常用动作都有快捷键（下表就是全部键位），面板里也各自有一行，不用去命令面板里翻。

AI 教练：你自己的 Key

不绑账号、不订阅、不上传代码到我们的服务器。填一个 OpenAI 兼容的地址和自己的 API Key 就能用， 不填也完全不影响编译运行。

怎么配

  1. 侧栏 Olympia → AI 教练与帮助 → AI 设置（地址 / 密钥 / 模型）
  2. 填 baseUrl，Key 在密码框里输入（存在系统密钥库，不写进配置文件）
  3. 模型列表自动从 /models 拉，拉不到就手动填，两行一个
  4. 地址只要是 OpenAI 兼容就行，哪家都行：例如 DeepSeek 填 https://api.deepseek.com/v1。 额度、价格、怎么充值都是那家服务商的事，Olympia 不经手、不抽成，也看不到你的 Key。

怎么用

配好之后在聊天面板里直接问就行——教练就是这个面板的默认回答者，它会自动带上当前文件的代码。想更聚焦就用三个指令：

  • /wa：结合题面、样例与你的输出，列出最可能的错因和验证方法
  • /hint：只给方向性提示与关键不变量，不输出完整代码
  • /check：提交前风险清单：边界、溢出、复杂度、读入终止、多组数据
  • 跑样例判出错时，通知里就有「问教练」：题号、判定、哪一组样例、期望与你的输出，一次填进输入框，不用你复述题目

常见问题

这算不算「VS Code 装了个插件」？

不是。Olympia 是 VS Code 的 fork，竞赛功能改在工作台本身：侧栏容器、状态栏、标题栏、菜单、 出厂主题和默认设置都在产品里，安装完就是竞赛环境，不需要再去扩展市场装东西。

装完提示「已阻止未识别的应用」/ SmartScreen？

因为安装包还没有代码签名证书。点「更多信息」→「仍要运行」即可，这只影响第一次； 安装器本身是 Inno Setup 生成的标准程序，装完之后的 Olympia.exe 也在 %LocalAppData%\Programs\Olympia IDE，可以随时删干净。

360 / 电脑管家之类的安全软件也可能把它当陌生程序：装之前先在官网核对校验值， 被误报就加白名单，不要因为弹了提示就换别的下载站。

怎么确认我下的包没被动过？

发行页同目录有 SHA256SUMS.txt。Windows 自带工具就能核对，不用装任何东西—— 在安装文件所在文件夹的地址栏输入 cmd 回车，然后：

certutil -hashfile OlympiaSetup-1.bin SHA256

把输出的那串和 SHA256SUMS.txt 里对应文件那行比一下。 用引导安装器（OlympiaSetup-web.exe）就不用手动核对：它每下完一个分卷自己算一遍， 对不上会直接停下并说是哪一片。

我的设置和题目存在哪儿？换机器、重装怎么办？

三处，各自独立：程序装在 %LocalAppData%\Programs\Olympia IDE（当前用户目录， 不要管理员权限）；设置与界面状态在 %AppData%\.olympia-ide\User； 题目、集训清单和你自己的模板都在工程文件夹里的 .olympia\ 下。

所以换机时把题目文件夹拷走就够了——练习记录跟着文件夹走， 不跟着账号走。AI 教练的密钥存在系统密钥库里，不在上面任何一个文件夹中， 换机器要重新填一次（这是有意的：它不该被拷进 U 盘）。

卸载就是删掉安装目录；想连设置一起清干净，再删 %AppData%\.olympia-ide。

需要联网吗？

编译、运行、体检、模板、题面文件全部离线。只有拉取在线题面和 AI 教练需要网络， 两者都是可选功能，不配也不影响其他部分。

支持 macOS / Linux 吗？

v1.0 只出 Windows x64 —— 竞赛机房的现实就是 Windows，所以先把这一个平台做透。 macOS 和 Linux 不是不做，是在路线图上，只是还没排到。具体什么时候能出，现在还给不出日期， 但不会一直只有 Windows。
