Olympia 没有服务器

这句话能解释下面全部内容：Olympia 不发数据回我们，也没有账号系统。 需要联网的两个功能——拉在线题面和 AI 教练——都是你的机器直连你指定的地址。

我们不收集什么

不注册、不登录

产品没有账号体系，也不需要邮箱、手机号。我们不知道谁在用 Olympia， 也就无从收集与之绑定的任何信息。

遥测出厂关闭

产品内置 enableTelemetry = false，使用统计与崩溃报告都不会发送。 这一项在代码里是产品开关，不是设置项，用户不需要自己去关。

不读你的代码

编译、体检、跑样例、对拍、比赛模式、模板都在本机执行。 你的源码不会因为「软件需要联网」而出门。

完全本地的功能

下面这些即使拔网线也能用，不发生任何网络请求： 编译与运行、评测机档位、提交前体检、跑样例判定、对拍、比赛模式、ACM / IOI 模板、 打开已经缓存的题面、编辑器的全部基础功能。

唯一的例外是扩展市场：只有你主动搜索或安装扩展时，编辑器才会向 open-vsx.org 发请求。

会联网的两个功能

拉取在线题面

你的机器直接向洛谷、Codeforces、AtCoder 请求对应题目页面， 不经过我们的服务器，也不携带任何本机标识。抓取到的题面存进你自己工作区的缓存目录。

题面内容的版权归原题站与作者，Olympia 只是把它显示在你正在用的编辑器里。

AI 教练

只有你填写了服务地址并主动提问时才会发请求，请求直接发往 olympia.ai.baseUrl 指定的地址——通常是你自己订阅的 DeepSeek、OpenAI 兼容服务， 或者本机跑的 Ollama。我们既不是转发方，也不是接收方。

随请求带过去的是你当前打开的代码和题目上下文，这是让回答有用的前提； 数据在你所选服务的使用协议下处理，请把这份声明一起转给学校和家长说明这一点。

API Key 存在哪里

Key 通过密码框输入，保存在 本机加密存储里（Olympia 的应用状态库，用你 Windows 账户的 密钥加密，对应 VS Code 的 SecretStorage）， 不会写进 settings.json，不会出现在同步配置里，也不会打进日志。

  • 设置文件里只有 olympia.ai.baseUrl 与 olympia.ai.models，不含密钥
  • 想清除：在 AI 设置里对 Key 选「清除」即可。系统「凭据管理器」里不会有这个条目，去那里找不到
  • 不用 AI 教练就什么都不用填，其他功能不受影响

本机留下的文件

位置内容怎么清掉
工作区\.olympia\problems抓下来的题面（Markdown）直接删目录
工作区\stress-fail对拍不一致时留下的数据与两份输出直接删目录
%APPDATA%\Olympia界面配置、扩展状态、运行日志删目录，或卸载时勾选清除用户数据
%LOCALAPPDATA%\Programs\Olympia IDE程序本体与内置工具链用「设置 → 应用」里的 Olympia IDE (User) 卸载

日志只写在本机，不会被上传；出现故障时你可以自己选择把哪段日志贴进 issue。

关于未成年使用者

Olympia 面向中学阶段的竞赛学习，因此刻意做成「不需要账号、不上传内容、可以完全离线」的形态。 如果学校或家长要求连 AI 教练也不使用，把 olympia.ai.baseUrl 留空即可： 所有联网功能都要使用者主动点击才会发生。

问题与更改

这份声明如有变化，会同时更新页面顶部的日期。 对本声明或产品有任何问题，可以在源码仓库提 issue， 用中文描述就行。
